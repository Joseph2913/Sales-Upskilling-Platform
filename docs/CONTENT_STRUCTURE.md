# Content Structure

## Learning Model Overview

The platform teaches sales capability through 6 objectives, each delivered in 3 formats. Users don't see all 6 — their personalised pathway (generated by AI from the onboarding survey) assigns a subset at varying depths.

This mirrors the AI Upskilling platform's "Levels → Topics → Phases" model but adapts it for sales: Objectives → Formats (A, B, C).

## The 6 Sales Objectives

Derived from the GFT Green Line Sales Academy (file 03), Sibelco's "Find More / Win More / Grow More" framework (file 10), and the IQVIA salesforce optimisation pillars (file 07).

| # | Objective | Focus | Source |
|---|-----------|-------|--------|
| 1 | Consultative Selling Foundations | Building trust, TRICIS model, becoming a trusted advisor, identifying sweet-spot organisations | Green Line Course 1 |
| 2 | Selling Strategies | Five strategies (Frontal, Encirclement, Bypass, Retreat, Alliance), COBA framework, competitive positioning | Green Line Course 2 |
| 3 | Objection Handling & Closing | Benefit articulation, storytelling, self-convincing questions, pricing techniques, closing complex deals | Green Line Course 3 |
| 4 | Account Management & Growth | Managing and growing accounts, share of wallet, stakeholder mapping, power matrix | Sibelco "Grow More" + Green Line |
| 5 | Change Management for Sales | Change agent skills, overcoming resistance, communicating change, influencing styles | Grey Line (file 02) |
| 6 | Data-Driven Sales & AI Tools | Using data for targeting, positive deviance, AI-assisted pre-call prep, capability gap analysis | IQVIA files 07, 08, 09 |

## The 3 Formats (Per Objective)

Each objective is experienced through three distinct learning formats, gated sequentially:

### Format A: Decision Simulation
**Unlocked by default for assigned objectives.**

A structured, branching scenario where the user navigates sales situations by making choices at key decision points. AI-generated scenarios based on the objective's frameworks.

**Structure (adapted from the e-learning player):**
- Fixed 460px height player with dot navigation
- 8-12 decision stages per simulation
- Each stage: situation description → 3-4 response options → consequence + coaching insight
- Final debrief: optimal path, frameworks relevant, key takeaway
- Replayable with different choices

**Content mapping from knowledge base:**
- Objective 1 scenarios: based on GFT ABE #1 (FEBRABAN) case study patterns
- Objective 2 scenarios: based on ABE #2 (SCHRODERS) competitive strategy patterns
- Objective 3 scenarios: based on ABE #3-4 (SANTALUCIA) closing/negotiation patterns
- Objective 4 scenarios: based on Sibelco "BYOA" (Bring Your Own Account) exercise patterns
- Objective 5 scenarios: based on Grey Line Course 2 resistance-to-change role plays
- Objective 6 scenarios: based on IQVIA pre-call preparation patterns

### Format B: AI Customer Conversation
**Unlocked after completing Format A.**

A live, generative dialogue where the user practises a real sales conversation. The AI plays a realistic buyer persona. No pre-scripted paths — fully dynamic.

**Structure:**
- Scenario briefing card (client profile, situation, your objective)
- Live chat interface (user types, AI responds in character)
- Minimum 8 turns to complete
- AI provides hidden coaching notes (revealed post-conversation)
- Post-conversation feedback report: score, strengths, missed opportunities, framework usage

**Persona design principles (from file 09):**
- Personas match the objective's context (e.g., skeptical CTO for Objective 2, resistant middle manager for Objective 5)
- Difficulty scales with user seniority from their profile
- AI stays in character throughout — never breaks the fourth wall during conversation
- Feedback only appears after conversation ends

### Format C: Build & Apply
**Unlocked after completing Format B.**

The user creates a real sales artefact and submits a project applying the objective's frameworks to their actual work context.

**Structure:**
- Personalised project brief (from their AI-generated learning plan)
- AI-assisted artefact builder (scaffolds the structure, user fills in their context)
- Evidence submission: text write-up + optional screenshots
- AI review: S/A/B/C/R score + structured feedback
- Must pass (C or above) to complete the objective

**Artefact types by objective:**
- Objective 1: Stakeholder trust assessment, TRICIS self-evaluation
- Objective 2: COBA competitive analysis, selling strategy selection matrix
- Objective 3: Objection handling playbook, closing technique guide
- Objective 4: Account growth plan, power matrix, stakeholder map
- Objective 5: Change readiness assessment, resistance mitigation plan
- Objective 6: Data-driven targeting plan, AI-assisted pre-call brief template

## Onboarding Survey → Pathway Assignment

The onboarding survey (in JourneyPage) collects: role, function, seniority, industry, sales experience, primary challenge, goal, weekly availability.

The AI pathway generator uses this to:
1. Select which objectives to assign (typically 3-5 of 6)
2. Set depth per objective: 'full' (all 3 formats), 'fast-track' (Format A + C only), 'awareness' (Format A only), 'skip'
3. Generate custom project briefs connecting each objective to the user's stated challenge
4. Estimate total duration

**Example pathways:**

Junior Account Executive (Tech, low experience):
→ Objectives 1, 2, 3 at full depth + Objective 4 fast-track. ~8 weeks.

Senior Sales Director (Pharma, high experience):
→ Objectives 4, 5, 6 at full depth + Objective 2 awareness. ~5 weeks.

New Sales Manager (Industrial, mid experience):
→ Objectives 1, 2, 3, 4, 5 at full depth. ~12 weeks.

## Practice Arena (Aggregated View)

The Practice Arena page (`/app/practice-arena`) shows all Decision Simulations (Format A) across all assigned objectives in a single library. Users can replay completed simulations or try new ones. Organised by objective, with difficulty filters (foundation / intermediate / advanced).

## Sales Coach (Aggregated View)

The Sales Coach page (`/app/sales-coach`) shows all AI Customer Conversations (Format B) across all assigned objectives. Users can start new conversations, review past transcripts, or re-read feedback reports. Organised by objective, with scenario filters.

## Artefacts Library

All outputs from Format C (and any saved mid-exercise work from A and B) appear in the Artefacts page (`/app/artefacts`). Filterable by: objective, artefact type, date, search text. Quick-use panel for preview, export, and duplication.
